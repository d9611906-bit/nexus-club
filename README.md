# NEXUS CLUB — игровой сайт с входом по паролю

Полноценное веб-приложение: регистрация и вход по логину и паролю, список
участников (виден только вошедшим), достижения, статистика. Работает в любом
браузере. Пароли хранятся в защищённом виде (PBKDF2), база — SQLite.

## Файлы
- `server.py` — серверная часть (Python, только стандартная библиотека, ничего ставить не надо)
- `index.html` — страница с входом и интерфейсом
- `nexus.db` — база данных (создаётся автоматически при первом запуске)
- `render.yaml` — маршрут для автоматического деплоя на Render

## Запуск локально
```
python server.py
```
Откройте `http://localhost:8080` в браузере. Остановить — `Ctrl+C`.

## Как выложить сайт в интернет (чтобы заходили все)

Сделать отдельным зарегистрированным. Проект — серверная программа, ей нужен
Python-хостинг. Бесплатно и просто через **Render.com**:

### Шаг 1. Аккаунт GitHub (нужен, чтобы хранить код)
1. Зайдите на https://github.com и создайте аккаунт (email + пароль).
2. Нажмите **New repository** (зелёная кнопка), название, например `nexus-club`.
3. Оставьте репозиторий пустым или для простоты сразу загрузите код (см. Шаг 2 альтернативно).

### Шаг 2. Загрузите код
Самый простой способ — загрузить файлы прямо в браузере на GitHub:
1. В своём репозитории нажмите **Add file → Upload files**.
2. Перетащите `server.py`, `index.html`, `render.yaml` и `requirements.txt` (если есть).
3. Нажмите **Commit changes**.

### Шаг 3. Деплой на Render (бесплатный план)
1. Зайдите на https://render.com → **Sign up** и зарегистрируйтесь **по кнопке «GitHub»** (даст доступ к репозиторию).
2. Нажмите **New + → Web Service**.
3. Выберите репозиторий `nexus-club`.
4. Render сам подтянет настройки из `render.yaml` (имя, команда `python server.py`, план free). Если не подтянул — вручную: Runtime: **Python**, Start command: `python server.py`, Instance type: **Free**.
5. Нажмите **Create Web Service**.
6. Подождите 2–4 минуты, пока не появится зелёный статус **Live**.
7. Ссылка вида `https://nexus-club.onrender.com` — это и есть ваш сайт в интернете. Отправляйте её кому угодно.

## Дальше по желанию
